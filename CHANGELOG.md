# Changelog

## 0.1.0-alpha.1 — 2026-10-13

- First public alpha of the `course-tutor` skill and LearnShelf local web library.
- Imports hierarchical course outlines and persists books, chapters, lessons, sources, and learning records.
- Supports layered Markdown, formulas, SVG, quizzes, flashcards, guided reading, fixed interactive widgets, and sandboxed custom experiments.
- Includes light, dark, and system themes plus a bundled demo library.

This release is unfinished and may contain incompatible changes in later `0.x` versions.
